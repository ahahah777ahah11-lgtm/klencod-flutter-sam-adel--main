# مدير الديون الذكي برو SMS — Smart Debt Manager Pro SMS

تطبيق Android احترافي مبني بالكامل بأحدث تقنيات **Kotlin** و **Jetpack Compose** وقاعدة بيانات **Room Database** المحلية وفق بنية **Clean Architecture / MVVM**.

---

## 🌟 المبادئ الأساسية المحققة
1. **محلي أولاً 100% (Offline-First):** تخزين جميع البيانات والعمليات المالية والعملاء محلياً على الجهاز دون الحاجة لأي خوادم خارجية أو اتصال بالإنترنت.
2. **محرك الحسابات المالية الدقيق:**
   - المعادلة الأساسية: **الرصيد المتبقي = إجمالي الديون المسجلة − إجمالي المدفوعات المسددة**.
   - الحركات المالية هي مصدر الحقيقة الوحيد.
   - التحقق من المبالغ (رفض الصفر والقيم السالبة).
   - منع تجاوز الرصيد في المدفوعات إلا عند تفعيل سياسة "الرصيد الدائن" صراحةً من الإعدادات.
   - التعديل والإلغاء الموثق (Reversal) مع سجل تدقيق مالي كامل (Audit Log).
3. **عزل وسلامة سجلات العملاء:**
   - تعديل الاسم أو الهاتف أو العنوان لا يغير ولا يحذف العمليات السابقة.
   - التحقق من تكرار رقم الهاتف.
   - أرشفة آمنة للعملاء كبديل مفضل للحذف.
4. **مركز رسائل SMS والتذكيرات:**
   - دعم القوالب الديناميكية وتخصيصها.
   - استبدال المتغيرات: `{اسم_العميل}`، `{الرصيد}`، `{إجمالي_الديون}`، `{إجمالي_المدفوعات}`، `{التاريخ}`، `{اسم_المتجر}`، `{رقم_التواصل}`.
   - معاينة كاملة للرسالة قبل الفتح في تطبيق الرسائل الرسمي للجهاز عبر Intent قياسي، دون طلب أي صلاحيات حساسة في الخلفية.
   - توثيق سجل الرسائل التي تم تجهيزها ومتابعتها.
5. **إدارة الحوالات الواردة (Transfers):**
   - تسجيل الحوالات من شركات الصرافة (النجم، الامتياز، داديه، الأكوع، إتش بي، الكريمي، وغيرها).
   - منع التكرار برقم المرجع واسم الشركة.
   - مطابقة الحوالات وترحيلها المباشر كدفعة مالية مسددة للعميل مع توثيق المرجع.
6. **كشوف الحسابات والتقارير:**
   - توليد كشف حساب تفصيلي للعميل مع الرصيد الافتتاحي وحركات الفترة والرصيد الختامي.
   - إمكانية مشاركة كشف الحساب منسقاً أو نسخه بنقرة واحدة.
   - تصدير بيانات العملاء والعمليات بصيغة CSV.
7. **النسخ الاحتياطي والاستعادة:**
   - نسخ احتياطي متكامل بصيغة JSON (`SmartDebtManager-backup.json`).
   - معاينة والتحقق من سلامة البنية قبل الاستعادة.
   - استيراد CSV مع تسجيل الأرصدة المستوردة كأرصدة افتتاحية موثقة دون اختلاق حركات وهمية.
8. **الهوية البصرية:**
   - واجهة عربية أصيلة RTL مدعومة بخط Cairo العربي المدمج محلياً.
   - الثيم الافتراضي: الأزرق المالي الداكن (`#103B59`) والفيروزي (`#00D5D9`).
   - الثيم البديل: الأحمر والأبيض (`#C0192F`).
   - دعم الوضع الداكن والفاتح والتلقائي.
   - أيقونة تطبيق متكيفة مصممة خصيصاً للتطبيق.

## 🛠️ البنية التقنية
- **اللغة:** Kotlin 2.2.10
- **واجهة المستخدم:** Jetpack Compose + Material 3
- **قاعدة البيانات:** Room 2.7.0 مع KSP
- **التصميم المعماري:** MVVM + Repository Pattern + Kotlin Flow
- **الاختبارات:** JUnit4 + Robolectric Testing

- اختبار عدم تأثر العمليات المالية بتعديل بيانات العميل.
- اختبار كشف أرقام الهواتف المكررة.
- اختبار استبدال متغيرات القوالب.
- اختبار تصدير واستعادة النسخ الاحتياطية.
- نجاح بناء وتشغيل الاختبارات: `BUILD SUCCESSFUL`.
